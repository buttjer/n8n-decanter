75	## Setup
76	
77	Requires **Node >= 22.18** (no build step — the CLI runs natively via Node's
78	type stripping). Needs an n8n with the built-in **MCP server** (~2.20+):
79	enable it once (Settings → MCP) and flip **"Available in MCP"** on each
80	workflow you want to sync — **only opted-in workflows can be pulled**.
81	
82	```sh
83	npm install -g n8n-decanter
84	n8n-decanter init [dir]   # OAuth in your browser (or a pasted MCP token)
85	n8n-decanter pull         # pick a workflow from the list → it pulls
86	```
87	
88	On a terminal, `pull` with no argument lists your n8n workflows — pick one and
89	it lands in `workflows/<slug>/`. Know the id already? `n8n-decanter pull
90	<id-or-name>` pulls it directly (scriptable, no TTY needed).
91	(`decanter.config.json`'s optional `"workflows"` array just sets the default
92	set a bare `pull`/`push`/`status` acts on.)
93	
94	**Credentials:** OAuth by default (via `init`); `N8N_MCP_TOKEN` for
95	headless/CI; `N8N_API_KEY` is optional, needed only for `executions`,
96	`data-tables`, and `backup`. Details: [Installation](docs/getting-started/installation.md),
97	[init](docs/cli/init.md), [Configuration](docs/concepts/configuration.md).
98	
99	## Works with n8n's official skills
100	
101	n8n-decanter pairs with the **[official n8n skills](https://github.com/n8n-io/skills)**
102	— n8n's first-party agent knowledge pack — rather than replacing them: they
103	teach your agent the n8n runtime and build workflow structure over MCP, which
104	is n8n's job here. The one boundary is **Code-node source**, and it's already
105	enforced: the scaffolded `.mcp.json` routes your agent's n8n MCP traffic
106	through [`mcp connect`](docs/cli/mcp-connect.md), a guard that forwards
107	everything except writes to a Code node's `jsCode` — those redirect back to
108	the repo (edit the file, `push`). No secret to manage.
109	
110	**A first [`init`](docs/cli/init.md) prints the install commands** for Claude
111	Code, Codex, or any skills.sh-supported agent, listing the one it detects first.
112	
113	**Full guide: [Using n8n's official skills](docs/agents/n8n-skills.md).**
